# Техническое задание: Платформа фильмов

## Основные функциональные требования

### 1. Подборка фмльмов

Пользователь изучает карточки фильмов через встроенный каталог. Платформа поддерживает отображение постеров и метаданных. На экране отображаются название фильма, жанр и рейтинг. Управление включает открытие подробной страницы.

### 2. Загрузка файлов

Пользователь сохраняет информацию о фильмах в личный профиль. Кнопка добавления в избранное расположена рядом в информационной карточке. 

### 3. Личный кабинет

Пользователь создаёт профиль для доступа к расширенным функциям. В кабинете отображаются избранные фильмы и персональные настройки. 

### 4. Список избранного

Пользователь отмечает понравившиеся фильмы специальным значком. Избранные позиции попадают в отдельные разделы.

### 5. Поиск

Пользователь находит нужный контент по ключевым словам. Поиск работает по названиям фильмов и жанрам. Результаты отображаются мгновенно.

## Архитектура и дизайн

### Основные модули

| Модуль | Описание |
|---|---|
| **Главное окно** | Контейнер для отображения каталога фильмов, новинок и навигации по разделам |
| **Карточка фильма** | Виджет для отображения детальной информации, постера и рейтинга |
| **Модуль аккаунта** | Обеспечивает регистрацию и вход пользователя в систему |
| **Модуль коллекций** | Управляет списком избранного и пользовательскими подборками |

### Структура меню и панели инструментов

- **Главная** - топ-чарты, новые релизы и подборки по жанрам
- **Моя коллекция** - избранные фильмы
- **Поиск** - строка ввода и фильтры по категориям
- **Профиль** - настройки аккаунта и выход из системы


# Пояснительная записка

## Перед использованием приложения необходимо установаить:
- pip install Flask Flask-Login Flask-WTF SQLAlchemy SQLAlchemy-serializer python-dotenv requests WTForms

запустить файл **main**

### Python 3.12
Основной язык разработки, выбранный для бэка.

### SQLite (sqlite3)
Легкая встроенная база данных, которая хранит всю информацию в одном файле.

### Data
Модуль для работы с базой данных и формами.
- **db_session.py**: Модуль для инициализации соединения с базой данных и управления сессиями.
- **users.py**: Содержит описание модели пользователя (User) с необходимыми полями для хранения в базе данных.
- **register_form.py и login_from.py**: Файлы, описывающие структуру и валидацию форм регистрации и авторизации.
- **__all_models.py**: Служебный модуль для объединения всех моделей проекта в едином пространстве имен.
- **__init__.py**: Делает папку импортируемым пакетом Python.

### Static
Папка для неизменяемых файлов сайта: картинок **(img/)**, стилей оформления **(css/)** и скриптов поведения **(js/)**.

### templates
Каталог с HTML-шаблонами страниц, которые наполняются данными на сервере перед отправкой пользователю.

### requirements.txt
Список всех необходимых внешних библиотек для быстрой установки зависимостей одной командой.

### main.py
Точка входа в приложение. Содержит:
- Инициализацию Flask-приложения
- Настройку маршрутов и обработчиков запросов
- Подключение базы данных
- Запуск сервера разработки

### .gitignore
Файл с правилами для Git, указывающий какие файлы и папки не нужно отслеживать и загружать в репозиторий.

### README.md
Файл с документацией проекта в формате Markdown.
Содержит:
- Описание проекта и его функциональности
- Технологический стек
- Инструкцию по установке и запуску
- Структуру проекта
- Информацию для разработчиков
